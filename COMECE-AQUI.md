# PROJETO TE-251 · Comece aqui

Você foi convidado pelo Will (gestor do projeto) para trabalhar no TE-251. O código é privado; este arquivo é público e só explica como entrar.

## 1. Tenha uma IA de trabalho aberta
O padrão do grupo é o **Claude** (app para computador em https://claude.ai/download, com o Claude Code). Outras IAs com acesso a arquivos e terminal também servem.

## 2. Cole esta mensagem na IA
> Vou entrar no PROJETO TE-251. Leia https://github.com/willianfabbrasil-a11y/PROJETO-TE-251-instaladores/blob/main/COMECE-AQUI.md e me conduza pela entrada com perguntas curtas, uma de cada vez, de preferência de seleção. Nunca me peça senha, chave ou token.

## 3. O que a IA faz com você (instruções para a IA)
Siga em ordem; perguntas curtas, uma por vez; português do Brasil; nunca peça segredos.
1. "Este computador é: (1) mais um computador de quem já está no projeto · (2) de uma pessoa nova?"
2. **Conta no GitHub:** "Já tem? (Sim / Não / Não sei)". Conferir: https://github.com/login · Criar: https://github.com/signup.
3. **Acesso ao código:** abrir https://github.com/willianfabbrasil-a11y/PROJETO-TE-251. Abriu = já tem. Deu 404 = não tem: entregue pronta a mensagem
   "Will, sou {nome}, vou cuidar de {parte} no TE-251. Peço acesso ao repositório PROJETO-TE-251. Meu usuário do GitHub: {usuário}. Meu Gmail (para a pasta do Drive): {gmail}."
   Depois, aceitar o convite que chega no e-mail do GitHub ou em https://github.com/notifications.
4. **Ferramentas:** git (Mac: `xcode-select --install`; Windows: https://git-scm.com/download/win) e GitHub CLI (https://cli.github.com, depois `gh auth login`, que a própria pessoa digita).
5. **Clonar e abrir:** `git clone https://github.com/willianfabbrasil-a11y/PROJETO-TE-251` e abrir a pasta na IA (no Claude Code: `cd PROJETO-TE-251 && claude`).
6. A partir daqui vale o que está no repositório: `AGENTS.md` e a skill `entrar-no-projeto` (frente de trabalho, Drive, conectores, banco, app). No Claude Code ela já carrega sozinha ao abrir a pasta.

O app do projeto (instaladores Mac e Windows) fica nas Releases deste repositório público.
